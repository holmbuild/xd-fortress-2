## Install

1. Steam: install **Team Fortress 2**.
2. Steam: go to **Library**, open the menu above your game list (it says **Games**) and tick **Tools**. Find **Source SDK Base 2013 Multiplayer** and install it.
3. Download the zip: **[XD_Fortress_2_mod_tf.zip](https://github.com/holmbuild/xd-fortress-2/releases/latest/download/XD_Fortress_2_mod_tf.zip)**
4. Unzip it into `Steam\steamapps\sourcemods` (usually `C:\Program Files (x86)\Steam\steamapps\sourcemods`; make the `sourcemods` folder if it is missing). You should get `sourcemods\mod_tf\gameinfo.txt`.
5. Restart Steam and start **XD Fortress 2** from your library.

## Update

Close the game and double-click `update.cmd` in `sourcemods\mod_tf`.
